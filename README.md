# MOTO MANIA

名作「モトクロスマニアックス」へのオマージュ。横視点モトクロスの**周回レース**で、
CPUライバルと固定サーキットを競います。アクセル・ターボに加え、**空中で前後にリーン**して
フリップや着地姿勢をコントロールするのが肝。ライブラリもビルドも不要。
バニラ JavaScript と HTML5 Canvas だけで動きます。

## 操作

| 操作 | キーボード | 画面ボタン |
| --- | --- | --- |
| アクセル | → / D / L | 右下「GO」 |
| ターボ | Space / Shift / X | 右「T」 |
| 後傾（空中で背面回転・着地で前輪上げ） | ↑ / W / K | 左「▲」 |
| 前傾（空中で前面回転） | ↓ / S / J | 左「▼」 |
| 再レース（リザルト画面） | Enter / タップ | 画面タップ |

## 遊び方

- スタートのカウントダウン後、**アクセルを握って前進**。**ターボ**でさらに加速できます。
- ターボはゲージ制。コース上の**ターボパネル「T」**で回復するので、**どこで使うかの配分が勝負**。
- ジャンプ中は**↑↓でバイクを回転**できます。着地時に**車体の傾きが地形と大きくズレているとクラッシュ**。
  大きく飛ぶときほど姿勢を立て直して着地しましょう（軽いジャンプは無操作でもだいたい決まります）。
- 名物ギミックが満載：
  - **360度ループ**…速度が乗っていれば駆け上がれます。
  - **ジャンプ＆ピット**…ジャンプ台で切れ目を飛び越える。届かず落ちるとクラッシュ。
  - **スプリング（バネ台）**…踏むと真上へ大ジャンプ。空中姿勢の制御が必要。
  - **トンネル**…天井が低い区間。飛び上がって**頭をぶつけるとクラッシュ**。
- **CPUライバル（青いバイク）**と周回勝負。既定3周。**先にゴールすれば WIN**、先着されると LOSE。
- クラッシュしても**少し時間をロスして直前から復帰**（レースは進み続けます）。
- 勝った時の**クリアタイム**を自己ベストとして自動保存。固定シードなので毎回同じサーキットで競えます。
- 横画面（よこ持ち）推奨です。

## GitHub Pages で公開する

1. GitHub で **nitromoto** という名前の空のリポジトリを作成します（README・ライセンスは付けないでください）。
2. このフォルダから push します。リモート（SSH）は設定済みなので、次の1行だけで送れます。

   ```bash
   git push -u origin main
   ```

   別の名前にした場合や HTTPS を使う場合は、先に URL を変更してください。

   ```bash
   git remote set-url origin git@github.com:<ユーザー名>/<リポジトリ名>.git
   ```

3. リポジトリの **Settings → Pages** を開き、**Build and deployment** を
   **Deploy from a branch** にして、Branch を **main** / フォルダを **/ (root)** に設定して保存します。
4. 数十秒後、`https://<ユーザー名>.github.io/nitromoto/` で公開されます。

## チューニング

挙動の数値は [`js/config.js`](js/config.js) に集約しています。

| 項目 | 効果 |
| --- | --- |
| `ACCEL` / `DRAG` | アクセル巡航速度を決める（平衡速度 = `ACCEL/DRAG`） |
| `TURBO` / `TURBO_BURN` / `TURBO_PICKUP` | ターボ加速 / 毎秒消費 / パネル1枚の回復量 |
| `LEAN_ACCEL` / `LEAN_AV_MAX` / `AIR_PITCH` | 空中リーンの効き / 角速度上限 / 無操作時の自然回転 |
| `LAND_TOL` | 着地許容角（大きいほど着地が甘い＝簡単） |
| `LAPS` / `TIME_LIMIT` | 周回数 / フェイルセーフの制限時間（秒） |
| `RIVAL_ACCEL` | ライバルの強さ（`RIVAL_ACCEL/DRAG` が巡航速度。大きいほど手強い） |
| `RESPAWN_DELAY` / `COUNTDOWN` | クラッシュ復帰待ち（＝失う時間） / 開始カウントダウン |
| `LOOP_SAFETY` | ループ突破に必要な速度の余裕（小さいほど簡単） |
| `SPRING_VY` / `TUNNEL_GAP` | スプリングの打ち上げ初速 / トンネル天井の高さ |
| `SEED` | サーキット生成シード（固定＝毎回同じコース） |

コース構成は [`js/track.js`](js/track.js) の `buildLapTemplate` 内の難所シーケンス
（`seq` 配列：ループ・ジャンプ・スプリング・トンネルの並び）で調整できます。
1周ぶんを生成して `LAPS` 周ぶんタイル接続し、末尾にゴールを置きます。

## ファイル構成

```
index.html          画面・HUD（タイム・ベスト・ラップ・順位・速度・ターボ）・操作ボタン
css/style.css       全画面キャンバスとUI・操作パッドのスタイル
js/
  main.js           エントリポイント（固定タイムステップのループ／HUD・リザルト更新）
  config.js         物理・空中リーン・レース・コースの調整パラメータ
  game.js           レース進行（カウントダウン／ラップ／ゴール／ループ・スプリング・トンネル・リスポーン）
  physics.js        バイクの物理（地上の加速、空中リーン回転、着地姿勢判定）
  track.js          周回サーキット生成（地形・ピット・ループ・スプリング・トンネル・ターボ）
  rival.js          CPUライバル（同コースをペース走行する対戦相手）
  renderer.js       Canvas 描画（ゴール／ラップ旗／ライバル／空中フリップ含む）
  input.js          キーボード＋画面ボタン入力（アクセル／ターボ／前後リーン）
  score.js          タイム・速度換算とベスト判定
  storage.js        ベストタイムの保存（localStorage）
tests/              node:test による単体テスト
```

## テスト

```bash
node --test
```

物理（空中リーン・着地姿勢・ループ速度）、コース生成（周回のシームレス接続・ループ前ターボ保証）、
ライバルの完走などを検証します（外部依存なし）。
