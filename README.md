# BLUEBIRD

> *bluebird* — 降雪の翌日の、抜けるような快晴。スキーヤーが一年で一番待ちわびる日。

**無限に続く山を、ただ気持ちよく滑り降りるだけのスキーゲーム。**
スコアもタイムもクリア条件もありません。急ぐ理由は、ひとつもない。

ライブラリ・ビルドツール・外部アセットは **ひとつも使っていません**。
地形も、木も、スキーヤーも、効果音も、音楽も、全部その場でコードから作っています。
素の JavaScript と WebGL2 と Web Audio だけで動きます。

---

## 遊び方

| 操作 | キー | 内容 |
| --- | --- | --- |
| カービング | `A` `D` / `←` `→` | **じわっと倒すほど、きれいに刻める。** 一気に倒すとエッジが抜ける。 |
| タック | `W` / `↑` | 前傾して抗力を減らす。速いが、操作性は落ちる。 |
| プルーク | `S` / `↓` | ハの字。両方のエッジが効くので、**低速でも確実に止まれる**。 |
| 抜重ジャンプ | `Space` 長押し → 離す | 沈み込んで弾く。**地形の凸と合わせると大きく飛ぶ。** |
| 空中スピン | `A` `D` | 回転。着地時に進行方向と揃っていないと崩れる。 |
| グラブ | `Space`（空中） | 回転が速くなる。スタイル。 |
| リセット | `R` | 好きなときにスタートへ戻る。 |
| カメラ / 消音 | `C` / `M` | |

ターンが切り替わる瞬間には、**自動的に内側のストックを突きます**。
実利はありませんが、スキーのリズムはここで決まります。

ゲームパッド（左スティック・A・RT・LT）とスマホのタッチにも対応しています。

## このゲームの唯一の仕組み

**丁寧に滑るほど速くなり、速くなるほど丁寧に滑るのが難しくなる。**

板は「横滑りを、グリップの限界まで打ち消すもの」としてしかモデル化していません。
カービングもずらしも減速も、そこから勝手に生まれます。

- ゆっくり板を回す → 横滑りが小さい → エッジが受け止める → 削れない → **速くなる**
- 速く雑に回す → 横滑りがグリップを超える → ずれる → 雪を削る → **遅くなる**

スキーはエッジが 2 枚あるぶん立ち上がりが速く、プルークなら低速でも確実に止まれます。
そのかわり、逆向き（スイッチ）の着地は板ほど得意ではありません。

そして **FLOW が最高速そのものを上げます**（56 km/h → 最大 124 km/h）。
速くなると、旋回半径は伸び、グリップの余裕は減り、バンプの衝撃は増える。
つまり自動的に難しくなる。ミスすれば FLOW が落ち、速度も落ちて、また立て直せる。

難易度を押し付ける仕組みは、ひとつも入れていません。
**ゆっくり安全に滑るのも、正解です。**

### ミスは即転倒ではありません

ミスは **BALANCE** を削ります。削られると体勢が崩れ（操作が勝手に振れ、カメラが揺れ）、
クリーンに滑れば回復します。0 になって初めて転倒。
高速での立木への正面衝突だけは、さすがに一発です。

転倒すると **スタート地点へ戻されます**。だから「攻めるか、守るか」に意味が出ます。

## 山

Y が上、**+Z 方向へ滑り降ります**。進んだ距離 = z（メートル）。
地形は完全に解析的・決定論的な純関数なので、**全員が同じ山にいます**。どこまでも続きます。

### ゾーン（約 380m ごとに切り替わり、84m かけて溶け合う）

| ゾーン | 内容 |
| --- | --- |
| **オープンバーン** | 広い圧雪。高速巡航。 |
| **樹林帯** | 圧雪路が細くなり、木の間に**サイドトンネル**が 2 本通る。 |
| **テレインパーク** | テーブルトップ 5 本、ヒップ、ジブボックス 3 本。 |
| **ボウル** | 圧雪路は細く、まわり一面がパウダー。崖と自然のリップ。 |
| **キャットトラック** | 細い道。片側は落ちている。アイスバーンが多い。 |
| **コブ斜面** | 深いコブ。リズムを合わせれば飛べるし、合わなければ弾かれる。 |

### 雪質

| 種類 | 手触り |
| --- | --- |
| **圧雪** | よく食いつく。コーデュロイの筋が見える。 |
| **パウダー** | グリップは落ちるが、ずらして乗るのが正解。押しのける抵抗で遅い。**轍が残る。** |
| **アイスバーン** | 一番速いのに、一番刺さらない。急斜面の圧雪面に現れる。 |
| **パーク** | 締まっていて、少しだけよく走る。 |

圧雪路の外は全部滑れます。雪面には **2 本のシュプール**が刻まれ、後から見返せます
（他の人のシュプールも残ります）。
サイドトンネルは近道になることが多いけれど、木が近く、自然のギャップと崖があります。
**危険なことをやり切ったこと自体が報酬**という設計なので、それ以上のご褒美はありません。

### 地形から自然に飛ぶ

キッカーもロールの裏も段差も、専用の処理は入れていません。
「面に沿い続けるのに必要な加速度が、重力＋膝の吸収を超えたら弾かれる」という
一本のルールだけで、全部そこから生まれています。

## 見た目と音

**見た目**：手続き的な空（レイリー近似・太陽・雲・遠景の稜線）／暖色の直射光と青紫の影／
高周波ハッシュによるきらめき（画面密度に追従するので遠くでも粒のまま）／圧雪のコーデュロイ／
アイスへの空の映り込み／**ワールド空間にタイリングした 2 本のシュプール**／
プレイヤー追従のシャドウマップ／風でしなるインスタンス樹木／雪煙・パウダープルーム・着地の爆発・
舞う粉雪／ブルームと**太陽のグレア**／ACES トーンマップ／速度に応じた放射状ブラーと色収差／
FLOW で暖かくなるカラーグレード。

**音**：全部その場で合成しています。雪面はノイズをバンドパスに通したもので、
カットオフを速度で、Q をエッジ角で動かしています（パウダーは低く柔らかく、アイスは高く硬く）。
きれいに乗れているときだけ鳴る**エッジの唸り**（板 2 枚ぶん、わずかに周波数をずらした共振を
2 本重ねてある）、風、板のバタつき、**ストックを突く音**、抜重ジャンプ、着地、転倒。
リバーブは**ノイズから生成したインパルス応答**の畳み込みで、空中では深くなります。
BGM は D リディアンの生成音楽で、**FLOW が上がるとレイヤーが増えます**。

## オンライン

全員が同じシードの、同じ山にいます。地形が決定論的なので、やり取りするのは座標と姿勢だけ。
画面左のリーダーボードに、**今それぞれがどこまで下っているか**が出ます。

```bash
node server/server.js 8080      # ゲームの配信も兼ねる。依存パッケージはゼロ。
```

ブラウザで <http://localhost:8080/> を開けば、そのまま複数人で同じ山に入れます。
サーバは RFC 6455 を手書きした WebSocket リレーです（`server/server.js`）。

- 別のサーバに繋ぐ: `?server=wss://example.com/ws`
- ひとりで滑る: `?solo=1`

**サーバに繋がらないときは、黙ってソロになります。**
そのときも山には「地元の人たち」（AI スキーヤー）が滑っています。
リーダーボードでは名前が斜体になっているのが彼らです。

> GitHub Pages のような静的ホスティングにはリレーが置けないため、
> `?server=` を明示しない限りオンラインには繋ぎにいきません。

## 動かす

ES Modules を使うので、`file://` で直接開かずローカルサーバー経由で開きます。

```bash
node server/server.js        # http://localhost:8080/  （オンラインも有効）
# もしくは配信だけなら
python3 -m http.server 8000
```

### GitHub Pages で公開する

1. `git push -u origin main`
2. **Settings → Pages** で **Deploy from a branch** → **main** / **/ (root)**
3. 数十秒後、`https://<ユーザー名>.github.io/nitromoto/` で遊べます（ソロ）。

### テスト

```bash
node --test
```

地形（連続性・必ず下ること・決定論性・ゾーン分布・キッカーの実在）と、
物理（FLOW が最高速を上げること、**丁寧に滑るほうが速く遠くまで行けること**、グリップ限界、
抜重ジャンプ、キッカーで実際に飛べること、ミスが即転倒でないこと、
低速で詰まないこと、数値の健全性）を検証します。

## 調整する

数値はほぼ 2 箇所に集約しています。

- **手触り**: [`js/play/rider.js`](js/play/rider.js) の `CFG`
  （`V_BASE`/`V_BONUS` で速度域、`GRIP_ACCEL` でエッジの強さ、`YAW_RATE` で舵の効き、
  `WEDGE_GRIP`/`BRAKE_DECEL` でプルークの効き、`FLOW_GAIN`/`FLOW_*_LOSS` で FLOW の経済、
  `ABSORB` で飛びやすさ、`SWITCH_PENALTY` で逆向き着地の難しさ）
- **山**: [`js/world/terrain.js`](js/world/terrain.js) の `ZP`（ゾーン別パラメータ）と
  `KICKERS` / `BOXES`（パークの構成）、`P0`/`A1..A3`（斜度のうねり）
