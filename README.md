# NITRO MOTO

名作「モトクロスマニアックス」へのオマージュ。スマホ向けの横視点モトクロス・
**タイムアタック**です。固定コースを周回し、**制限時間**内にゴールを目指します。
ライブラリもビルドも不要。バニラ JavaScript と HTML5 Canvas だけで動きます。

## 遊び方

- バイクは**常に前進**します。**画面をタップ＆ホールド**すると**ターボ**で加速（ボタンは1つだけ）。
- ターボはコース上の**ターボパネル「T」を拾う**と回復。残量は下のゲージで確認できます。
- **制限時間内に規定の周回（既定2周）を走り切ってゴール**すれば成功。クリア**タイム**が記録され、ベストは自動保存されます。
- 名物ギミックが満載：
  - **360度ループ**…手前でターボを使い、十分に加速していれば駆け上がれます（速度不足だと落下クラッシュ）。
  - **ジャンプ＆ピット**…ジャンプ台で切れ目を飛び越える。届かず落ちるとクラッシュ。
  - **スプリング（バネ台）**…踏むと真上へ大ジャンプ。
  - **トンネル**…天井が低い区間。飛び上がって**頭をぶつけるとクラッシュ**なので、ここではターボでの跳ね上げに注意。
- **ライバル**がペース走行で先行します（半透明のゴースト）。追い抜いてゴールを目指しましょう。
- クラッシュしても**少し時間をロスして直前から復帰**（時計は止まりません）。ゴール／タイムアップ後はタップで再挑戦。
- 横画面（よこ持ち）専用です。

## ローカルで動かす

ES Modules を使うため、`file://` で直接開くのではなくローカルサーバー経由で開きます。

```bash
cd /home/mihara/開発/モトクロス
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000> を開けば遊べます。

## GitHub Pages で公開する

1. GitHub で **nitromoto** という名前の空のリポジトリを作成します（README・ライセンスは付けないでください）。
2. このフォルダから push します。リモート（SSH）は設定済みなので、次の1行だけで送れます。

   ```bash
   git push -u origin main
   ```

   別の名前にした場合や HTTPS を使う場合は、先に URL を変更してください。

   ```bash
   git remote set-url origin git@github.com:<ユーザー名>/<リポジトリ名>.git
   ```

3. リポジトリの **Settings → Pages** を開き、**Build and deployment** を
   **Deploy from a branch** にして、Branch を **main** / フォルダを **/ (root)** に設定して保存します。
4. 数十秒後、`https://<ユーザー名>.github.io/nitromoto/` で公開されます。

## チューニング

挙動の数値は [`js/config.js`](js/config.js) に集約しています。

| 項目 | 効果 |
| --- | --- |
| `ENGINE` / `DRAG` | 巡航速度を決める（平地の平衡速度 = `ENGINE/DRAG`） |
| `TURBO_THRUST` | ターボ加速の強さ |
| `TURBO_BURN` / `TURBO_PICKUP` | ターボの毎秒消費量 / パネル1枚の回復量 |
| `LAPS` / `TIME_LIMIT` | 周回数 / 制限時間（秒） |
| `PAR_RATIO` | ライバルのペース（`TIME_LIMIT × この割合`でゴール） |
| `RESPAWN_DELAY` | クラッシュ後の復帰待ち（＝失う時間） |
| `LOOP_SAFETY` | ループ突破に必要な速度の余裕（小さいほど簡単） |
| `SPRING_VY` / `TUNNEL_GAP` | スプリングの打ち上げ初速 / トンネル天井の高さ |
| `SEED` | コース生成シード（固定＝毎回同じ地形でタイムアタック） |

コース構成は [`js/track.js`](js/track.js) の `buildLapTemplate` 内の難所シーケンス
（`seq` 配列：ループ・ジャンプ・スプリング・トンネルの並び）で調整できます。
1周ぶんを生成して `LAPS` 周ぶんタイル接続し、末尾にゴールを置きます。

## ファイル構成

```
index.html          画面とHUD（残り時間・ベストタイム・ラップ・速度・ターボゲージ）
css/style.css       全画面キャンバスとUIのスタイル
js/
  main.js           エントリポイント（固定タイムステップのループ／HUD更新）
  config.js         物理・レース・コースの調整パラメータ
  game.js           レース進行（時間・ラップ・ゴール／ループ・スプリング・トンネル・リスポーン）
  physics.js        バイクの物理（エンジン＋ターボ、接地⇄空中の状態遷移）
  track.js          周回コース生成（地形・ピット・ループ・スプリング・トンネル・ターボ配置）
  renderer.js       Canvas 描画（ゴール／ラップ旗／ライバル含む）
  input.js          タップ／スペースキー入力
  score.js          タイム・速度換算とベスト判定
  storage.js        ベストタイムの保存（localStorage）
tests/              node:test による単体テスト
```

## テスト

```bash
node --test
```

物理・タイム・コース生成（周回のシームレス接続やループ前のターボ保証など）を検証します（外部依存なし）。
