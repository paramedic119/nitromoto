# BLUEBIRD — 設計仕様

> *bluebird* = 降雪の翌日の快晴。スキーヤーが一年で一番待ちわびる日。

無限に続く山を、気持ちよく滑り降りるためだけのスキーゲーム。スコアも制限時間もない。
ライブラリ・外部アセットゼロ。WebGL2 + Web Audio を素の JavaScript で書く。

---

## 1. 設計の中心にある一つの考え

**「丁寧に滑るほど速くなり、速くなるほど丁寧に滑るのが難しくなる」**

これだけでフロー状態が自然に生まれる。難易度を押し付ける仕組みは一切入れない。
ゆっくり安全に滑るのも正解。それが楽しいならそれでいい。

### FLOW（フロー値 0..1）
| 上がる | 下がる |
| --- | --- |
| きれいなカービング（横滑りが少ない） | ずらし・スキッド |
| 滑らかなステアリング入力 | ガクガクした操作 |
| 柔らかい着地（スタンプ） | 硬い着地 |
| エッジを保持したままのターン | アイスバーンでのスリップ |
| 回転を決めて着地 | 木・岩への接触 |

FLOW は**最高速度そのもの**を上げる（`vMax = V_BASE + flow * V_BONUS`）。
速度が上がると自動的に：旋回半径が伸び／グリップ限界が近づき／バンプの衝撃が増える。
＝ 難しくなる。ミスすれば FLOW が落ち、速度も落ちて、また立て直せる。**自己調整ループ**。

### BALANCE（バランス 0..1）
ミスは即転倒ではない。BALANCE を削る。削られると体勢が崩れ（よろけ・カメラ揺れ・
操作の鈍り）、クリーンに滑れば回復する。0 になって初めて転倒。
高速での立木への正面衝突だけは即転倒。

転倒 = **スタート地点へ戻される**（距離リセット）。だから「攻めるか守るか」に意味が出る。

## 2. 山

Y が上、スキーヤーは **+Z 方向へ滑り降りる**。`distance = z`（メートル）。

### 高さ関数（すべて決定論的・解析的）
```
h(x,z) = base(z)               斜度が z に沿って緩急する基本斜面（積分で連続）
       + valley(dx,z)          谷形状（トレイルから離れるほど盛り上がる）
       + macro fbm             60〜200m のうねり（ロール・ニー）
       + zone deform           ゾーン別の地形（モーグル/ボウル/キャットトラック段差）
       + features(x,z)         キッカー・ボックス・リップ・崖
       + surface micro         圧雪＝滑らか / パウダー＝細かいギャップ
```
`base` は斜度 `pitch(z) = S0 + a1 sin(z/L1) + a2 sin(z/L2+φ)` の**解析的積分**で定義。
斜度は約 8°〜25° の間を行き来する。急斜面と緩斜面のリズムが生まれる。

### ゾーン（z 方向 ~420m ごと、ハッシュで決定、60m かけてブレンド）
| ゾーン | 内容 |
| --- | --- |
| `OPEN` | 広い圧雪バーン。高速巡航。 |
| `GLADE` | 樹林帯。メイン圧雪路は細くなり、木の間に**サイドトンネル**が通る。 |
| `PARK` | テレインパーク。テーブルトップ・ヒップ・ボックス。 |
| `BOWL` | 広大なパウダーボウル。崖・自然のリップ。 |
| `NARROWS` | 細いキャットトラック。片側は段差（ドロップ）。 |
| `MOGULS` | コブ斜面。リズムを合わせれば飛べる。 |

### 面（サーフェス）
| 種類 | grip | drag | 見た目 |
| --- | --- | --- | --- |
| `GROOMED` 圧雪 | 高 | 低 | コーデュロイの筋、明るい |
| `POWDER` 非圧雪 | 中 | 高（沈む） | 深い、スプレーが大きい、**2 本のシュプールが残る** |
| `ICE` アイスバーン | **低** | 最低（速い） | 青くツヤツヤ、空を映す |
| `PARK` パーク | 高 | 低 | やや締まった雪 |
| `ROCK` 岩 | — | — | 障害物 |

アイスバーンは急斜面の圧雪上に fbm マスクで出現。速いが刺さらない。エッジを立てすぎると流される。

### ライン（メイン路とサイド路）
- メイン圧雪路：`cx(z)` の蛇行スプライン。幅は z で変動（狭くなる所が緊張感）。
- サイド路：`cx(z) ± offset` に 2 本。樹林の密度がそこだけ落ちて**トンネル**になる。
  近道になることが多いが、木が近く、自然のギャップと崖がある。危険＝報酬は「決めたこと」そのもの。
- 圧雪路の外は全部滑れる。パウダーに**溝が刻まれ、後から見返せる**（軌跡テクスチャ）。

## 3. 操作

| 操作 | キー | 内容 |
| --- | --- | --- |
| カービング | `A` `D` / `←` `→` | 押し込むほどエッジ角が立つ。速度で旋回半径が変わる。 |
| タック | `W` / `↑` | 抗力減・加速。ただし操作性が落ちる。 |
| プルーク | `S` / `↓` | ハの字。両エッジが効くので低速でも確実に止まれる。 |
| 抜重ジャンプ | `Space` 長押し→離す | 沈み込んで弾く。地形の凸と合わせると大きく飛ぶ。 |
| 空中スピン | `A` `D` | 回転。着地時に進行方向と揃える必要あり。 |
| グラブ | `Space`（空中） | 回転が速くなる＋スタイル。 |
| リセット | `R` | 好きなときにスタートへ戻る。 |

ターンの切り替わりでは自動的に**内側のストックを突く**（リズムと音のため）。

ゲームパッド（左スティック＋A/RT/LT）とタッチにも対応。

## 4. 見た目（juice）

- 手続き的な空：レイリー近似のグラデ、太陽ディスク＋グロー、fbm の雲、地平の霞。
- 雪シェーダ：暖色の直射光＋**青紫の影**（疑似 SSS）、高周波ハッシュによる**キラキラ**、
  圧雪のコーデュロイ法線、パウダーの微細な凹凸、アイスの鏡面反射（空をサンプル）。
- **カービング軌跡**：ワールド空間のトーラス巻きテクスチャに書き込み。溝＋掻き出された雪の縁。
  他プレイヤーの軌跡も残る。
- 影：プレイヤー追従の指向性シャドウマップ（PCF）。
- 木：インスタンシングした低ポリの針葉樹。枝に雪。風でしなる。
- パーティクル：エッジからの雪煙、パウダープルーム、着地の爆発、木を掠めた雪の落下、
  舞う粉雪（スピンドリフト）、高速時のコントレイル。
- ポスト：ブルーム、ACES トーンマップ、ビネット、色収差、フィルムグレイン、
  **速度に応じた放射状ブラー**、FLOW で暖かくなるカラーグレード。
- カメラ：スムーズ追従、カーブでバンク、着地で沈み込み、微細な手持ち揺れ、速度で FOV。
- 小物：リフトの鉄塔、コース標識、竹ポール、木の柵、パトロールの旗、ロッジ、鳥の群れ。

## 5. 音（すべて合成）

| 音 | 合成方法 |
| --- | --- |
| 雪面 | ノイズ → バンドパス（速度でカットオフ、エッジ角で Q）。パウダーは低く柔らかく、アイスは高く硬い。 |
| ストック | 突いた瞬間の短い高音。ターンのリズムを刻む。 |
| カービング | ノイズのスウェル＋ピッチが上がるレゾナンス。エッジを立てるほど鳴る。 |
| 風 | 2 系統のノイズ → バンドパス。速度で音量とカットオフ。 |
| 抜重ジャンプ | 短いクリック＋板のしなり（ピッチ落ちする三角波）。 |
| 着地 | ノイズバースト＋低いサイン波のサンプ。衝撃で変化。 |
| 空中 | ローパスがかかりリバーブが増える（静けさ）。 |
| BGM | リディアン旋法の暖かいパッド、マリンバ／ベル、柔らかいアルペジオ。FLOW でレイヤーが増える。 |

リバーブは**ノイズから生成したインパルス応答**の Convolver（開けた斜面／樹林帯で切替）。

## 6. オンライン

全員が**同じシード＝同じ山**にいる。決定論的地形なので座標を送るだけで一致する。

- クライアント → サーバ：15Hz で `{pos, yaw, roll, speed, distance, state}`
- サーバ → 全員：他プレイヤーの状態をまとめて中継
- 画面左に**リーダーボード**（誰が今どこまで下っているか）
- 他プレイヤーは補間して描画。軌跡も残る。
- サーバは **依存ゼロ**（RFC 6455 を手書き）の Node WebSocket リレー。
- サーバに繋がらない場合は自動でソロ。山には「地元の人たち」（AI スキーヤー）が滑っている。

```

css/style.css
js/
  main.js             起動・固定ステップループ・全体統合
  core/
    math.js           vec3 / mat4 / quat / 補間ユーティリティ
    rng.js            決定論的ハッシュノイズ・fbm・シード付き PRNG
    gl.js             WebGL2 ヘルパ（シェーダ・VAO・FBO・テクスチャ）
    input.js          キーボード／ゲームパッド／タッチ
  world/
    terrain.js        高さ場・法線・サーフェス判定（純関数・決定論的）
    scatter.js        木・岩・小物の決定論的配置
    chunks.js         地形チャンクのメッシュ生成とストリーミング
  play/
    rider.js          スキーヤーの物理・FLOW・BALANCE・プルーク・ストック・空中・転倒
    camera.js         追従カメラ
    trails.js         シュプール（軌跡）テクスチャ
    net.js            WebSocket クライアント・補間・リーダーボード
    locals.js         周囲を滑る AI スキーヤー
  gfx/
    shaders.js        全 GLSL
    renderer.js       シャドウ／メイン／ポストのパス構成
    meshes.js         手続き的メッシュ（木・スキーヤー・小物）
    particles.js      パーティクル
  audio/
    engine.js         AudioContext・マスターバス・IR 生成
    sfx.js            効果音シンセ
    music.js          生成音楽
  ui/
    hud.js            HUD・リーダーボード・トースト
server/
  server.js           依存ゼロの WebSocket リレー
tests/                node:test による単体テスト
```
